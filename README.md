# 🎬 Noor Al-Shefaa — Motion Graphics Reel Studio (1080x1920)

استوديو إنتاج ريلز رأسي تفاعلي مخصص لدراسات الحالة التقنية الطبية على نمط `@abdaal.dev`، مبني بالكامل باستخدام **React 19 + Vite + Tailwind CSS + Framer Motion**.

---

## 🚀 طريقة التشغيل السريعة

```bash
cd D:\final_nour\reel-studio
npm run dev
```

ثم افتح المتصفح على: `http://localhost:5174`

---

## 🎥 إعداد فيديو المذيع (Talking-Head Video)

1. **الخيار المباشر:** ضع ملف الفيديو الخاص بك بصيغة MP4 في مسار:
   ```
   D:\final_nour\reel-studio\public\talking_head.mp4
   ```
2. **الخيار التفاعلي من الواجهة:** اضغط على زر **"تحميل فيديو المذيع"** في الشريط العلوي لاختيار أي ملف فيديو محلي وتشغيله فوراً.
3. **في حالة عدم توفر الفيديو:** يتضمن الاستوديو تلقائياً شخصية مذيع افتراضية سينمائية مع موجات صوتية نابضة لتجربة كل الانتقالات.

---

## 🕹️ اختصارات لوحة المفاتيح والتحكم

- **مسافة (Space):** تشغيل / إيقاف مؤقت (Play / Pause).
- **مفتاح F:** تفعيل نمط **العرض النظيف الكامل (Clean Fullscreen Play 1080x1920)** لتسجيل الشاشة بدقة 60fps بدون أي أزرار أو حواف.
- **مفتاح ESC:** الخروج من العرض النظيف والعودة للوحة التحكم.
- **السهم الأيمن / الأيسر:** التقديم والترجيع بمقدار ثانيتين.
